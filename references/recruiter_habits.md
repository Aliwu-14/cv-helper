# HR 阅读模型与秒级扫读偏好

本文档总结招聘端在 6–8 秒首扫、60–90 秒深读、ATS 排序这三个层级上的真实偏好。所有规则源自 2026 年中国招聘市场公开数据、企业招聘系统厂商披露与 i人事 / eRoad / 飞书 HR 等平台的实测。

## 1. 三段式阅读节奏

| 阶段 | 时长 | 阅读者 | 关注 |
|------|------|--------|------|
| 秒级扫描 | 6–8 秒 | HR/ATS | 学校 + 公司 + 岗位 + 工作年限 |
| 半深阅读 | 60–90 秒 | HR | 技能关键词 + 量化成果 + 经历连贯性 |
| 业务深读 | 5+ 分钟 | 业务面试官 | STAR 完整故事 + 项目深度 |

生成简历时，三个阶段都要兼顾：扫描阶段靠清晰标题 + 关键词起首；半深阶段靠每段 1–2 条量化；深读阶段靠 bullet 完整链路。

## 2. 秒级扫描能找到什么

HR 在 6–8 秒内通常会主动扫描以下信息：

- 学校名（985/211/QS Top X 等关键词命中）；
- 公司名（业内知名 / 竞对 / 头部 / 上市公司）；
- 最近一段经历的岗位名；
- 工作年限（履历时间跨度）；
- 一两个硬技能关键词（出现在模块标题或第一行 bullet）。

为此：
- 个人总结用第一条直接给出"专业 / 职业背景 + 行业";
- 经历段头与技能模块标题要使用 ATS 标准英文/中文标题；
- 不要在最显眼的段落用空话或排版花活稀释关键词密度。

## 3. HR 权重与评分维度

主流 ATS 与 HR 的多维筛选权重常见分布：

| 维度 | 常见权重 | 候选人对齐方式 |
|------|----------|----------------|
| 技能 / 关键词匹配 | 30–50% | 技能模块 + 技能名出现在 bullet |
| 工作经历 / 项目深度 | 25–40% | STAR 压缩 + 量化 |
| 教育背景 | 10–20% | 学校名 + 专业 + 学历 |
| 行业 / 公司背景 | 5–15% | 段头行业属性 + 公司名 |
| 稳定性（在职时长、地域） | 5–10% | 时间连续、无长期空白 |
| 软技能 / 潜力 | 5–10% | 个人总结 + 自然能力语言 |

门槛通常按"必备 vs 加分"分两层：必备不足直接淘汰；加分多余再排序。

## 4. HR 用信号而不是标签

HR 普遍抗拒纯描述性自我评价，偏好"信号可观察"的能力表达：

- ❌ "具备较强的团队合作能力"
- ✅ "跨 6 部门协调 22 名执行成员，覆盖华北、华东 8 城"

因此：
- 个人总结里若用"网感好""产品sense""商业化意识""闭环意识"等自然能力表达，紧跟一句可观察的判断 / 转化 / 复盘；
- 工作 bullet 默认以行为为锚，不以形容词为锚；
- 删除"认真负责、积极向上、吃苦耐劳、抗压能力强"等无信号短语。

## 5. ATS 评分卡常见规则

不同厂商阈值不同，但 75% 是常见门槛：

- 关键词重合率（必备 + 加分）；
- 标题 / 模块完整性（必备字段全填）；
- 量化成果占比（≥ 30% bullet 含数字）；
- 简历长度（应届 ≤ 1 页、经验 ≤ 2 页）；
- 格式合法性（无表格/文本框/图）。

`scripts/validate_section.py` 内部的几个校验就来源于这种规则集。

## 6. 一致性与排版偏好

- 段落顺序倒序；
- 日期格式全篇统一；
- bullet 数量每个岗位内一致（不要 A 岗位 5 条 B 岗位 1 条）；
- 视觉风格（字体 / 颜色 / 留白）一致，不要中途切换模板；
- 关键词与缩写在全文写法一致，例如用了 `RAG` 就别又在另一处写成"检索增强生成"再写回 `RAG`；
- 同一份简历不要混用两种语言（中文版全文中文，英文版全文英文）。

## 7. 应届 / 转行 / 资深差异化

| 人群 | 关注点 | 排版 |
|------|--------|------|
| 应届 | 学校 + 专业 + 实习/项目 + GPA | 教育背景前置；强调实习、项目、竞赛 |
| 1–3 年 | 第一份工作 + 项目深度 + 量化 | 教育背景后置；强调项目贡献 |
| 3–7 年 | 行业 + 职级 + 管理半径 | 个人总结 + 工作经历并重；弱化教育背景 |
| 7 年以上 | 行业地位 + 战略级成果 + 团队规模 | 两页；个人总结以战略 + 框架能力开场 |

## 8. 隐性偏好清单

- 标题 / 公司 / 岗位 / 时间在一行写完，便于 ATS 抓取；
- 联系方式出现在正文最上方；
- 自我介绍 / 求职信里写明目标岗位名（很多 ATS 会以自我简介中的岗位名做分类）；
- 项目 / 实习期间若无量化结果，可以用"产品上线""方案被采纳"代替；
- 个人兴趣 / 奖项只在与岗位相关时保留（"全国数学建模竞赛 Top 1%"对数据分析岗加分）；
- 自我评价在中文简历里通常三句话之内；超过四行开始挤压可用空间，HR 阅读时长会反向缩短。
